# 수강신청 연습 (sugang-practice)

실제 영남대학교 수강신청 화면을 모방하여, 수강신청 시작 시각에 맞춰 빠르게 과목을 신청하는 반응속도를 연습할 수 있는 웹 페이지입니다.

🔗 [바로가기](https://nohhyun03.github.io/sugang-practice/)

## 주요 기능

- 로그인 화면 → 서버 접속 지연 대기 화면 → 수강신청 메인 화면 → 결과 화면으로 이어지는 실제 수강신청 플로우 재현
- 09:59:55.000 ~ 10:00:00.000 구간을 기준으로 한 타이머 시뮬레이션
- 신청할 과목 수, 서버 지연 모드 등 옵션 설정
- 로그인 시각, 수강신청 완료까지 걸린 시간 등 결과 기록 및 히스토리 제공

## 기술 스택

- HTML / CSS / JavaScript (프레임워크 없이 순수 바닐라로 구현)

## 프로젝트 구조

```
.
├── index.html      # 전체 화면(View) 마크업
├── css/
│   └── style.css   # 스타일
├── js/
│   └── main.js      # 타이머, 화면 전환, 수강신청 로직
└── img/             # 이미지 리소스
```

## 실행 방법

별도의 빌드 과정 없이 `index.html`을 브라우저로 열거나, 로컬 서버를 띄워 실행합니다.

```bash
npx serve .
```
